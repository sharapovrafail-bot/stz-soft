# Симулятор УП Fanuc

Программа для Windows: симуляция управляющих программ Fanuc для фрезерного **KVL 1000** (0i-MF) и токарного **DOOSAN PUMA 3050 LM** и отправка УП на станок по сети (FOCAS).

Текущая версия: **9.1.0** (11.11.2026).

## Что умеет
- **Мастер токарной обработки** (кнопка «Мастер» над текстом УП, режим Puma 3050 LM): деталь задаётся параметрами, как в Manual Guide — заготовка, контур по точкам (линия, дуга, фаска, радиус), операции (торец, наружное черновое/чистовое, сверление, расточка, канавка, резьба, отрезка). УП составляется сама — циклами G71/G70/G74/G75/G76 или развёрнутыми проходами — и сразу проигрывается в симуляции. Код мастера: `wizGenerate`, `wizContour` в `app/index.html`.
- Токарный вид: верхняя половина — разрез со штриховкой, нижняя — вид детали снаружи с объёмной заливкой; патрон с кулачками, резцы с пластинами и державками.
- Ширина панели программы и высота нижней панели меняются мышью, обе сворачиваются; кнопка «Крупно» оставляет один вид детали.
- Симуляция G-кода: траектория, съём заготовки, циклы, макросы, оценка времени цикла.
- Заготовка для фрезерной: авто по программе, прямоугольник или круг (цилиндр); в программе — комментарием (ZAGOTOVKA 120X80X30) или (ZAGOTOVKA D120 H30).
- Коррекция G41/G42: траектория центра смещается на радиус фрезы, контур детали из программы показан оранжевым пунктиром. На вкладке «Станок» можно выбрать «в программе центр фрезы (D = износ)» для Fusion «Износ».
- Дисковая (пазовая) фреза: режет только диск (ширина W, Ø шейки DS — на вкладке «Инструмент» или в комментарии `(T13 D=31.45 W=3 DS=16 SLOT MILL)`); материал считается 3D-моделью (DexelSim), видны канавки под стенкой; шейка проверяется на задевание.
- Разрез заготовки по XZ / YZ (убирается ближняя половина).
- Материал фрезерной считается три-декселем, как во Fusion (`TriDexelSim`: лучи по Z, X и Y, заметание инструмента по отрезкам), поверхность строится по точным точкам пересечения (`meshTri`) с затенением во впадинах (ambient occlusion) и острыми рёбрами. Наклонная обработка (B/C, G68.2) — прежний `DexelSim`.
- 3D-графика через WebGL в стиле симуляции Fusion 360 (`StockGL`): градиентный фон, сетки `meshHeight` и `meshNets` (гладкая поверхность, surface nets), объёмный инструмент с патроном (`meshTool`), траектория с буфером глубины по типам движений (`moveKind`: синий — резание, жёлтый — G0, зелёный — подвод/отвод, красный — врезание; пройденная часть яркая, остальная приглушена).
- Окраска заготовки: металл, по операциям (названия из комментариев Fusion, `Interp.ops`), по инструменту, по глубине, сравнение с моделью.
- «Заготовка: остаток по модели»: STL детали из Fusion (вкладка «Заготовка и нули»), привязка к G54, допуск; вертикальные лучи через модель (`ModelRays`), боковой остаток — по расстоянию до ближайшей стенки модели. Цвета как во Fusion: красный — зарез, зелёный — в допуске, синий — недоснято (светлее — меньше); галочка «Модель» показывает полупрозрачную деталь. Модель хранится в IndexedDB.
- «Заготовка: по инструменту» — каким инструментом снят металл.
- Режим ввода координат без десятичной точки отдельно для каждого станка: Puma 3050 LM — калькуляторный ввод (X20 = 20 мм), KVL 1000 — стандарт Fanuc (X20 = 0.02 мм).
- Кнопка **«На станок»**: отправка текущей УП по FOCAS. Список станков и IP берётся из настроек STZ & FANUC LAN (`C:\PTT\dist\ptt_settings.json`).
- **«Обзор…»**: выбор папки на стойке из списка (диски → папки → программы), подсветка программы с тем же номером.
- **«Открыть в STZ & FANUC LAN»**: УП сохраняется в `Документы\Симулятор УП Fanuc\На станок\`, и STZ & FANUC LAN открывается в этой папке.
- Открытие файлов `.nc` двойным щелчком (по желанию при установке).

## Устройство
| Файл | Что делает |
|---|---|
| `app/index.html` | весь симулятор (интерфейс, интерпретатор Fanuc, 3D). Тот же файл публикуется как веб-версия на claude.ai — там кнопки «На станок» нет. |
| `main.js` | окно Electron, открытие файлов, связь со станком и STZ & FANUC LAN |
| `preload.js` | мост `window.cncLink` между страницей и main.js |
| `focas.js` | передача и чтение папок по FOCAS через `koffi` |
| `afterPack.js` | записывает иконку и сведения о версии в exe (без wine) |
| `installer/setup.nsi` | установщик NSIS |
| `build/icon-1024.png` | исходник иконки (вариант №1 из ChatGPT); из него сделаны `build/icon.ico`, `build/icon.png`, `app/icon.png` |

**Важно про FOCAS:** номер соединения (handle) Fwlib действует только в потоке, который его открыл. Поэтому все вызовы FOCAS идут синхронно в одном рабочем потоке (`worker_threads` в `focas.js`). При вызовах из разных потоков стойка отвечает кодом −8.

## Сборка (на Linux, без wine)
```
cd software/simulyator-up
npm install
cp /путь/к/Fwlib64.dll /путь/к/fwlibe64.dll focas/      # из C:\PTT
npx electron-builder --win dir --x64                       # dist/win-unpacked
# уменьшить размер: оставить только нужные языки и сборку koffi для Windows
(cd dist/win-unpacked/locales && ls | grep -v -E '^(ru|en-US|de)\.pak$' | xargs rm -f)
K=dist/win-unpacked/resources/app.asar.unpacked/node_modules/koffi/build/koffi
ls $K | grep -v win32_x64 | sed "s|^|$K/|" | xargs rm -rf
cp build/icon.ico dist/ && cp installer/setup.nsi dist/
cd dist && makensis -INPUTCHARSET UTF8 setup.nsi           # Simulyator_UP_Fanuc_Setup_<версия>.exe
```
`makensis` для Linux есть в кеше electron-builder (`~/.cache/electron-builder/nsis-*/linux/makensis`, запуск с `NSISDIR` на эту папку).

## Новая версия
Номер меняется в пяти местах: `package.json` (version), `afterPack.js` (FileVersion), `main.js` (заголовок окна), `app/index.html` (метка «версия … » в шапке и список изменений в её подсказке), `installer/setup.nsi` (VERSION, OutFile, VIProductVersion).

## Важно для правок
- Таблица инструмента обновляется из комментариев ДО расчёта траектории (коррекция G41/G42 берёт радиус из неё); если после расчёта диаметры изменились — траектория пересчитывается.

## Проверка без станка
Отправку и обзор папок можно проверить на модели библиотеки FOCAS `focas/fake_fwlib.c` (диски, папки, программы, привязка handle к потоку как у настоящей Fwlib). Сборка на Linux: `gcc -shared -fPIC -o libfake.so focas/fake_fwlib.c -lpthread`, запуск программы с переменной окружения `SIM_FOCAS_DLL=/путь/libfake.so`.
