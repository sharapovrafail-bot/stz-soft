# История версий STZ WireCut

| Версия | Что добавлено |
|---|---|
| 1.0 | Ядро: DXF, черчение как AutoCAD, эквидистанта, пуансон/матрица, проходы, перемычка, постпроцессоры ISO и 3B, карта наладки, симуляция, передача (COM / папка), команда WCUT для AutoCAD. Два установщика: Win7 (.NET 3.5) и Win10/11 (.NET 4.8) |
| 1.1 | Новый интерфейс (тёмная тема, лента, подсветка G-кода, заставка) — по промту через Codex, доработан |
| 1.2 | Профиль станка SIMOS DK7750 · AutoCut 6.0: формат 3B, ход стола, толщина, папка AutoCut Work, подсказки по шагам в AutoCut |
| 1.3 | Библиотека: прямозубая шестерня (эвольвента, W), шпоночный паз ГОСТ 23360; врезание в вершину зуба |
| 1.4 | Все команды редактирования на ленте, компактные группы, окно на весь экран |
| 1.5 | Шлицы ГОСТ 1139 и 6033, внутренний венец; подобие, обрезать, удлинить, сопряжение, фаска, массив; проверка и починка DXF; стоимость; крупный шрифт, перенос ленты |
| 1.6 | Подсказки при наведении на все кнопки; руководство пользователя (F1) со снимками |
| 1.7 | Панель симуляции (пуск, пауза, стоп, шаг, ползунок, время); таблица режимов резания материал × толщина в терминах AutoCut (F4) |
| 1.8 | Линейки (F11), размеры (линейный, радиус, диаметр, угол), габарит (F12), размеры элемента под курсором |
| 1.9 | Размеры при построении как во Fusion 360: поля ввода, Tab, авторазмеры на объектах |
| 2.0 | Изменение детали щелчком по размеру (растяжение, длина, Ø/R); размеры у выделенных объектов и деталей из DXF |
| 2.1 | Заход проволоки: прямой / под углом / по дуге, длина, угол, радиус; сторона захода (снаружи/изнутри) для каждого контура |
| 2.2 | История изменений как во Fusion 360: «◄ Назад» (Ctrl+Z) и «Вперёд ►» (Ctrl+Y / Ctrl+Shift+Z) без ограничения в одну отмену, шкала истории под чертежом (щелчок — откат к шагу), группа «История» на ленте; в историю входят объекты, размеры, точки заправки и стороны захода; «Новый» и «Открыть DXF» тоже отменяются; «Новый» теперь очищает и размеры |
| 2.3 | Шпоночный паз: радиус r в углах дна паза по ГОСТ 23360-78 (среднее / наименьший / наибольший / свой / без радиуса), диапазон по ГОСТ в окне; если r меньше смещения проволоки — увеличивается с предупреждением; то же для паза в отверстии шестерни |
| 2.4 | Точки заправки и метки захода сбрасываются: кнопка «Сброс» на ленте (команда СБРОС), удаляются вместе со стёртым контуром и при открытии нового DXF (вместе с размерами); точка дальше 25 мм от контуров не используется (раньше старая точка тянула заход к новой детали с любого расстояния); «Заправка → У» завершает команду |
| 2.5 | Вход / выход проволоки вручную (как во Fusion 360): точки входа, заправки, выхода и схода для каждого контура; выход дальше входа — перекрытие, раньше — перемычка; группа «Заход проволоки» на ленте. Начало координат как во Fusion 360: точка со стрелками X / Y и плоскостью, привязка к нулю, команда «Ноль X0 Y0» (точка / центр габарита / левый нижний угол) |
| 2.6 | Больше места под чертёж: лента с вкладками ЧЕРТЁЖ / РАЗМЕРЫ И БИБЛИОТЕКА / ЭРОЗИЯ (одна строка вместо трёх), сворачивание ленты (двойной щелчок по вкладке, Ctrl+F1), скрытие панели свойств (F2), панель симуляции только во время симуляции, командная строка ниже; вид окна запоминается (ui.ini) |
| 2.7 | Новая иконка программы (ChatGPT): проволока, искра и шестерня в пластине — значок exe 16…256 px, установщики, ярлыки; логотип на заставке и в «О программе» (ресурс logo.png); исходник — art/icon_original_ChatGPT.png; новые снимки экрана в руководстве (вкладки, вход/выход, история), обновлено описание в «О программе» и установщике |
| 2.8 | Установщик: ярлыки на рабочем столе и в «Пуске» пересоздаются с явной иконкой (app.ico в папке программы), после установки сбрасывается кэш значков Windows (SHChangeNotify, ie4uinit) — новая иконка видна сразу. Папка «Для пользователей» (бесплатно, без лицензии и активации) |
| 2.9 | Связь с «STZ Расчёт зубьев»: файл колеса .stzgear (STZ beta.18: Экспорт → «Шестерня / Колесо / Венец → эрозия»), «Библиотека → Из STZ», двойной щелчок по файлу (ассоциация в установщике, передача в уже открытую программу); поле «Ø вершин задан» (уравнительное смещение пары); число зубьев в длине W по ГОСТ с учётом смещения; сверка da / df / W с STZ — 20 колёс совпали |
| 3.0 | Для монитора станка: 4 вкладки ленты (ЧЕРТЁЖ / ПРАВКА И РАЗМЕРЫ / БИБЛИОТЕКА / ЭРОЗИЯ) — каждая в одну строку от 1024 px; свёрнутая лента выпадает поверх чертежа и прячется после команды; на маленьком экране панель свойств 330 px и командная строка ниже; минимальный размер окна 800×560. Кнопка «На станок ▶» (Ctrl+F10): траектория → УП → сразу в AutoCut\\Work / флешку / RS-232 без окна УП, с вопросом при предупреждениях |
| 3.1 | Понятный вход / выход проволоки: подсказка по 4 шагам прямо на чертеже (что сделано, что дальше), стрелка направления резки, предпросмотр перекрытия (оранжевым) и перемычки (красным пунктиром) с длиной, траектория пересчитывается сразу после каждого контура, <kbd>Н</kbd> — шаг назад. Правка готовых точек: ВХОД, ЗАПРАВКУ, ВЫХОД, СХОД и точки заправки можно тянуть мышью (вход/выход скользят по контуру), правая кнопка по точке — меню (заправка по свойствам, выход в точке входа, сход авто, задать заново, удалить). Шкала истории: правая кнопка по шагу — удалить этот шаг (остальные сохраняются), вернуться к шагу, удалить все шаги до него, очистить историю |
| 3.2 | Папка станка задаётся вручную: кнопка «…» в Свойствах (5. Связь со станком → Папка станка), меню «Эрозия → Папка станка…» (команда ПАПКА) или впишите путь; выбранная папка запоминается, «На станок» и окно УП пишут только туда (нет папки — спросит и запомнит). Режимы резания вручную: параметр «Режимы вручную» (3. Проходы) — свои Ton, Toff, ток, трубки, V-F, зазор не заменяются таблицей при смене материала / толщины / станка; включается сам при правке любого значения прохода, «Нет» — снова из таблицы |
| 3.3 | Открытие DWG (AutoCAD): «Файл → Открыть DXF / DWG…» (Ctrl+O), добавление DWG в чертёж, запуск программы с файлом DWG и «Открыть с помощью → STZ WireCut» (AutoCAD остаётся программой по умолчанию). DWG → DXF: ODA File Converter, если установлен, иначе встроенный GNU LibreDWG 0.14 (папка dwg, GPL v3, файлы без изменений); конвертация в папке с латинским путём (ProgramData), временные файлы удаляются. Справка → «Что нового» |
