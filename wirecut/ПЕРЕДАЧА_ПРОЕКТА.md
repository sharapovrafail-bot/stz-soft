# Передача проекта STZ WireCut — контекст для нового участника

## Заказчик и задача
ООО «СпецТехЗаказ». Программа для эрозийного проволочно-вырезного станка: черчение без AutoCAD,
связь с AutoCAD (команда WCUT), расчёт траектории проволоки, УП, режимы, стоимость, передача на станок.

## Станок цеха
- **SIMOS CNC Technology DK7750**, 12.2016, сер. № 161218 (сервис в РФ — ООО «Доминик», Челябинск).
- Быстрая протяжка, проволока **молибден Ø0.18**. Ход стола **650×550 мм**, толщина до **500 мм**, конус **3° на 80 мм** (оси U/V есть).
- Стойка: компьютер с **Windows 7** и **AutoCut v6.0.171115**; папка программ `C:\AUTOCUT_6-20171116\AUTOCUT_6-20171116\Work`. Маленький монитор — нужен крупный шрифт.
- Станком управляет AutoCut через свою плату. STZ WireCut станком напрямую **не управляет** (протокол платы закрыт, управление подачей — в реальном времени); она готовит файл 3B и кладёт его в папку Work / на флешку.
- Часто режут **прямозубые шестерни** и **шпоночные пазы**. Косозубые на этом станке невозможны (нужен наклон = β 8–20°, станок даёт 3°).

## Что сделано (версия 3.3)
См. CHANGELOG.md. Кратко: черчение как AutoCAD/Fusion с размерами и изменением через размер, DXF, проверка/починка,
открытие DWG (LibreDWG / ODA), эквидистанта, пуансон/матрица, вложенные контуры, заходы (прямой / под углом / по дуге, снаружи / изнутри, ручные вход / выход / сход с перекрытием или перемычкой, подсказкой по шагам на чертеже, перетаскиванием точек мышью и меню по правой кнопке), начало координат с переносом детали к нулю, проходы,
перемычка, 3B/ISO, карта наладки, таблица режимов, библиотека (шестерни, шлицы, шпоночные пазы с радиусами по ГОСТ 23360), стоимость,
симуляция, лента с вкладками и сворачиваемыми панелями, линейки, история изменений с отменой/повтором и шкалой (как во Fusion 360; правая кнопка по шагу — удалить шаг), папка станка и режимы резания вручную, подсказки на всех кнопках, руководство (F1), два установщика.

## Связь с «STZ Расчёт зубьев» (с 2.9)
- STZ (Electron, лицензия по ключу, отдельный закрытый проект) — beta.18: Экспорт → «Шестерня / Колесо / Венец → эрозия (STZ WireCut)», файл `.stzgear`.
- Формат (JSON, UTF-8): `format: "STZ-WireCut-gear"`, `version: 1`, `name`, `internal`, `m`, `z`, `x`, `alpha`, `ha`, `cs`, `d`, `da`, `df`, `db`, `W`, `zw`, `mate`, `b`, `mat`, `acc`, `bore`, `key {b,h,t2}`, `note`.
- Программы не объединяются: STZ платный и на Windows 7 не работает, WireCut открытый и должен работать на ПК станка.
- Сверка расчёта (da, df, k, W) — 20 колёс, включая пары со смещением и внутренние венцы, совпали.

## НЕ проверено (важно!)
1. **Приём нашего 3B в AutoCut** — направление дуг (SR/NR, четверти). Проверка: простая деталь (прямоугольник с отверстием) → открыть .3B в AutoCut → сверить картинку → холостой прогон (Sim, генератор выключен) → пробный рез из обрезка.
   Лучше всего — сравнить с файлами, которые AutoCut создаёт сам (взять из папки Work).
2. **Таблица режимов** — общие ориентировочные значения для молибдена, не по паспорту DK7750. Заполнить реальными режимами цеха.
3. Сборка через `STZ_WireCut.csproj` в Visual Studio не проверялась (выпуски собраны mono + NSIS).

## Пожелания заказчика (как работать)
- Общение — на русском. Интерфейс программы — русский, крупный шрифт.
- Всегда два установщика: **Win7** и **Win10-11**.
- После сборки новой версии старые установщики и архивы исходников удалять сразу.
- В УП: нумерация кадров N10, N20, N30…; комментарии к операциям (для AutoCut — латиницей).
- Надпись «Сделано специально по заказу ООО «СпецТехЗаказ»» — в программе и установщике.
- Модели деталей приходят из Fusion 360 (DXF) и AutoCAD.
